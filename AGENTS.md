# Agents: shared rules for every AI tool in this repo

This file is for Google Antigravity, Gemini and any other agent. Claude reads `CLAUDE.md`. Both files say the same thing, and `CLAUDE.md` is the master copy.

1. Read `CLAUDE.md` and follow every rule in it. Its read order and hard rules apply to you too.
2. Coordinate through `handoff/BOARD.md` (below). Never work on a task another agent has claimed.
3. Branch names say who did the work: `dev/antigravity/<topic>` for you, `dev/claude/<topic>` for Claude. Never push to `main`. Open a PR.
4. Before you stop, update your task's line on the board and add a dated note to `handoff/LOG.md`.
